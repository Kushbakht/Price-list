# Khushbakht — персональный аналитик

Персональный коммерческий сайт: бизнес-аналитика, финансовый контроль, дашборды, автоматизация и аналитика строительных проектов.

Сайт: https://kushbakht.github.io/Price-list/

## Структура

- `index.html`: адаптивная страница, стили и демонстрационный дашборд без зависимостей JavaScript.
- `og-analyst.png`: карточка Open Graph (1734 × 907).
- `favicon.svg`: значок сайта.
- `.github/workflows/jekyll-gh-pages.yml`: существующая публикация GitHub Pages.

## Редактирование

Цены, тексты и контакты редактируются в HTML. Данные демонстрации находятся в объекте `views` в конце страницы и не являются клиентскими результатами. WhatsApp: +996 226 00 35 45. При изменении позиционирования обновляйте description, Open Graph, Twitter и изображение одновременно.

Минимальный проект: 120 000 сом. Внедрение и ежемесячное сопровождение имеют отдельную стоимость. Лицензии и нестандартные интеграции согласуются отдельно.

## Проверка

Открыть index.html или запустить любой статический HTTP-сервер. Проверить три переключателя демонстрации, якоря, FAQ и WhatsApp. У страницы предусмотрены адаптивные стили, видимый фокус, ссылка пропуска навигации и поддержка reduced motion.
